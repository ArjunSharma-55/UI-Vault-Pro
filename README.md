## ✦ About UI/UX Vault Pro

**UI/UX Vault Pro** is a frontend design inspiration library and interactive developer toolkit built for developers, designers, and creative minds.

It brings together **140+ carefully organized design ideas across 7 categories**, along with 4 interactive tools that help you experiment with CSS effects, color combinations, typography, and frontend code.

From a simple loading spinner to a complete mobile dashboard concept, explore different design possibilities without switching between multiple resources.

### The idea behind the project

- Discover creative UI inspiration.
- Explore modern CSS animations.
- Understand interactive design patterns.
- Experiment with colors and typography.
- Preview and copy available code snippets.
- Build better frontend experiences.

# 🛠️ Interactive Developer Studio

Not just inspiration. UI/UX Vault Pro also includes four practical tools.

### 🧊 01. CSS Glassmorphism Generator

Create and experiment with frosted-glass effects.

**Features:**
- Adjustable blur intensity.
- Background opacity control.
- Border transparency control.
- Real-time visual preview.
- Generated CSS output.
- One-click CSS copying.

### 🎨 02. WCAG Color Contrast Checker

Evaluate text readability against different background colors.

**Features:**
- Foreground color picker.
- Background color picker.
- Live contrast ratio calculation.
- WCAG AA evaluation.
- WCAG AAA evaluation.
- Live text readability preview.

### 🌈 03. Color Palette & Font Pairing Hub

Experiment with color combinations and typography.

**Features:**
- Curated color palettes.
- Click-to-copy HEX values.
- Multiple font combinations.
- Editable heading preview.
- Editable paragraph preview.
- Live font pairing changes.

### 💻 04. Live HTML/CSS Sandbox

Write frontend code and see the result immediately.

**Features:**
- Editable HTML/CSS code.
- Live browser preview.
- Automatic preview updates.
- Interactive code experimentation.
- Isolated preview using an iframe.

# 🚀 Run Locally

Want to explore the source code or customize the application?

**1. Clone the repository**

```bash
git clone https://github.com/ArjunSharma-55/UI-Vault-Pro.git
```

**2. Navigate to the project**

```bash
cd UI-Vault-Pro
```

**3. Launch the application**

Open `index.html` in your preferred browser.

No package installation or build command is required.
